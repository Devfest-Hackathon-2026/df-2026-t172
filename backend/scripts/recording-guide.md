# 音声の経路の技術検証：録音の手順

Speech-to-Text V2（`app/live/speech_v2.py`）に本物の録音を通し、話者分離・同期の認識の長さ・
話者の割り当て・数字の出方を確かめるための録音の手順。検証は `run_live_speech.py` で行う。

## 用意するもの

- **2人**：看護師役と患者役。**声の違う2人**にする（話者分離を確かめるため。1人で2役は不可）
- 台本：[利用シーン](../../docs/design/scenarios.md) の場面1〜5。**架空の台本だけ**を読む。
  録音の前後に、実在の人の名前（自分の名前も）を言わない（P-07）
- 録音の道具（どちらか）
  - **おすすめ**：[recorder.html](recorder.html) を Chrome で開く。アプリと同じ MediaRecorder
    （webm/opus）で録り、ファイルに保存するだけ（どこにも送らない）。マイクが使えないときは、
    `backend/scripts` で `python -m http.server 8765` を動かし、`http://localhost:8765/recorder.html` を開く
  - スマホの録音アプリ（m4a など）。検証スクリプトが ffmpeg で FLAC に直してから送る
- スマホかノート PC を、2人の間（ベッドサイドで看護師が持つ位置）に置く
- **保存先はリポジトリの外**（例：`C:\Users\suzuk\Documents\df26-audio\`）。音声はリポジトリに入れない（P-01）

## 録る4本（＋あれば1本）

台本の長さの目安は毎分300字。言い終わってから次の人が話し始めるまで、ふつうの会話の間（0.5〜1秒）を空ける。

| 名前 | 台本 | 誰が先 | 長さの目安 | 何を見るか |
|---|---|---|---|---|
| `r1_s3` | 場面3 | 看護師 | 約30秒（ゆっくりめ） | 60秒未満の基本の形。37.4度 |
| `r2_s2` | 場面2 | 看護師 | 約60〜70秒（間を多めに） | 60秒を少し超えたとき。血糖182 |
| `r3_s1s5` | 場面1 → **3秒黙る** → 場面5 | 看護師 | 約150秒 | 60秒を大きく超えたとき。36.8度・132の78・言い直し |
| `r4_s4p` | 場面4 の **u2 → u1 → u3〜u6** の順 | **患者** | 約25秒 | 患者が先に話すと、看護師と患者が入れ替わるか |
| `r5_s3_noise`（任意） | 場面3 | 看護師 | 約30秒 | ベッドサイドの雑音（テレビ・換気扇・廊下の声など）の中で |

- `r1`〜`r4` は**静かな部屋**で録る。`r5` は、テレビを小さく流すなどして雑音のある所で録る
- `r4` は、患者役が「ああどうも。隣の山本さん、昨日退院したんだってね」から始め、
  看護師役が「失礼しまーす、310号室です」と続ける。あとは台本どおり
- `r3` は場面1を最後（u18）まで読んだら**3秒黙り**、場面5を u1 から読む（2場面の境目が分かるように）
- 数字は台本どおりに読む（「36.8度」は「さんじゅうろく てん はち ど」、「132の78」は「ひゃくさんじゅうに の ななじゅうはち」）
- 読み間違えたら、止めずに言い直して続ける（言い直しも検証の材料になる）。大きく崩れたら録り直す

## 録った後

1. ファイル名を上の「名前」にして、リポジトリの外のフォルダに置く
2. フォルダの場所を検証のセッションに伝える（ファイルはチャットに貼らない）
3. 検証のセッションが、費用（単価×秒数）を出して承認を取ってから認識を呼ぶ
4. 検証が終わったら、録音は消してよい（デモ動画に使うなら残す。いずれにしてもリポジトリの外）

## 検証スクリプト（参考）

```bash
cd backend
python -m scripts.run_live_speech --probe                                  # 使えるモデルと機能（無料）
python -m scripts.run_live_speech --recording r1 --dry-run --out 結果のフォルダ  # 台本で流れだけ（無料）
python -m scripts.run_live_speech --recording r1 --audio 録音.webm --out 結果のフォルダ
python -m scripts.run_live_speech --recording r3 --audio 録音.webm --split 55 --max-calls 3 --out ...
```

ADC に quota project が付いていないときは `GOOGLE_CLOUD_QUOTA_PROJECT=df-2026-t172` を付ける。
結果（発言の列・話者の当たり・数・照合）は `--out` に JSON で書く。`--out` もリポジトリの外にする。
