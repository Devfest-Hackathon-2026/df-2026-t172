# 利用シーン（受け入れテストを兼ねる）

具体的な場面を決め、**この場面でアプリがこう動けば完成**という基準にする。3つの使い道がある。

1. **設計の確認**：画面や出力の形を、この場面に当てはめて足りないものがないか見る
2. **受け入れテスト（シナリオテスト）**：台本の会話を入力し、「期待する出力」のとおりになるかを確かめる。台本の文字起こしを固定の入力として自動テストにし、プロンプトを変えるたびに回す（spike/scenarios.json（開発用リポジトリの内部資料。提出用には含めていない） が同じ内容の機械用）。音声からの通しの確認は手で行う
3. **デモ動画**：同じ台本を録音して使う

- 人物・会話はすべて**架空**。実在の患者や病院の情報は使わない
- 場面は [ヒアリング記録](../research/hearing.md) で聞いた困りごとから作った。どの困りごとに当たるかを各場面に書く
- **実際のベッドサイドの会話は雑談に近い**と考え、記録に関係ない話（天気、家族、テレビ、他の患者の話）を混ぜてある。アプリは、雑談の中から記録に要る部分だけを拾う必要がある
- 台本と期待する出力は【変更あり】：場面と口調は Cさんの想定。実際の会話がこれに近いかは看護師に確認する（下の「看護師に確認すること」）

## 看護師に確認すること

| 確認すること | 何が変わるか |
|---|---|
| 実際の会話はどのくらい雑談が多いか。この台本の口調は近いか | 台本の現実味 |
| 測った値を声に出して言うか（「36.8度ですね」） | **声に出さないなら、バイタルを会話から取る前提が崩れる**。測定器から取る、画面で入れる、などに変える |
| 痛みの程度を10段階で聞くか | 自由記述の書き方 |
| 自由記述の書き方（SOAP など）、バイタルの取り方 | 期待する出力の形（すでに質問済み） |

## 合否の決め方（全場面共通）

AI の出力は毎回少しずつ違うので、文の一致では判定しない。次の観点で判定する。

| 観点 | 合格の条件 |
|---|---|
| 患者の照合 | 名簿で選んだ患者と、会話で言った部屋番号・名前の照合（コード）が、一致／照合できず／食い違いを正しく出す |
| バイタル | 会話に出た値がすべて、正しい項目・値で出る。**会話にない値・言い直し前の値が出たら不合格** |
| 根拠 | すべての要素に根拠の発言番号があり、3発言まで。数はその根拠の発言にある。話者が合っている（[設計](README.md) 5章の照合の規則） |
| 拾い漏れ | 雑談に混ざった症状の訴えを自由記述に拾う |
| 薬 | 薬の名前・量を自由記述に書かず、「手で入力が必要」に回す |
| 根拠のない文 | 会話に根拠のない内容を AI が書いたら、必ず「根拠なし」として目立つ |
| 抜け | 会話に出てこない必須項目が「抜け」に出る |
| 依頼 | 患者の依頼がすべてタスクに出る。依頼でないもの（雑談、その場で答えた質問）はタスクにしない |
| **雑談** | 記録に関係ない話（家族、趣味、天気、他の患者の話）が、記録・依頼・医師への確認に入らない |
| 判断しない | 診断名・医療的な判断・優先順位を AI が書いていない |

## 場面1：手術翌日の検温（基本の流れ）

**困りごと**：メモしてから入力し直す二度手間。患者からの依頼が埋もれる。医師への確認を忘れる。

**状況**：302号室の田中さん（架空、70代）。手術の翌日。看護師が朝の検温に来る。孫の話で盛り上がりながら測る。

**台本**

| 番号 | 話者 | 発言 |
|---|---|---|
| u1 | 看護師 | 田中さーん、おはようございます。302号室の田中さん、朝の検温に来ましたよ |
| u2 | 患者 | ああ、おはよう。今日は天気いいねえ |
| u3 | 看護師 | ほんとですね、昨日の雨が嘘みたい。お熱測りますね、脇に挟んでください |
| u4 | 患者 | はいはい。昨日さ、孫が見舞いに来てくれてね、もう小学生なんだよ |
| u5 | 看護師 | えー、いいですね！何年生なんですか |
| u6 | 患者 | 3年生。サッカーやっててさ、今度試合なんだって |
| u7 | 看護師 | 応援に行けるように早く良くならないとですね。あ、鳴りました。36.8度ですね |
| u8 | 看護師 | 血圧も測りますねー。132の78、脈は76です |
| u9 | 患者 | 傷がさ、夜中ちょっとズキズキして、あんまり眠れなかったんだよね |
| u10 | 看護師 | そうでしたか。痛みは10段階でいうとどれくらいですか |
| u11 | 患者 | 今は、4くらいかなあ。夜はもうちょっとあった |
| u12 | 看護師 | ちょっと傷見せてくださいね。赤くなったり腫れたりはしてないですね |
| u13 | 患者 | そういえばさ、ご飯っていつから食べられるの？病院のご飯でもいいから食べたいよ |
| u14 | 看護師 | ですよね。先生に確認してお伝えしますね |
| u15 | 患者 | あとタオルもう1枚もらえる？汗かいちゃって |
| u16 | 看護師 | わかりました、あとで持ってきますね |
| u17 | 患者 | テレビカードってどこで買うんだっけ |
| u18 | 看護師 | 談話室の前に販売機がありますよ |

**期待する出力**

| 種類 | 中身 | 根拠 |
|---|---|---|
| 患者 | 302号室 田中さん | u1 |
| バイタル | 体温 36.8℃、血圧 132/78、脈拍 76 | u7, u8 |
| 自由記述（患者） | 夜間に創部痛あり、あまり眠れなかったとの訴え。現在の痛みは 4/10、夜間はそれ以上 | u9, u11 |
| 自由記述（看護師） | 創部に発赤・腫脹なし | u12 |
| 抜け | 呼吸数、SpO2（会話に出てこない） | — |
| 依頼 | タオルをもう1枚 | u15 |
| 医師への確認 | 食事の開始時期 | u13, u14 |

**見るべき点**

- 孫・サッカー・天気の話を記録に入れない
- テレビカードの質問は、その場で答え終わっているのでタスクにしない
- 「眠れなかった」は患者の訴えとして書き、看護師の観察（不眠）にすり替えない

## 場面2：リハビリ帰りと食前インスリン（依頼と手がかり）

**困りごと**：食前インスリンの患者がリハビリから戻って先に食べてしまう、職種間で伝わらない、という懸念。

**状況**：305号室の佐藤さん（架空、60代）。食前にインスリンを打つ。昼前にリハビリから戻ったところ。理学療法士の話をしながら。

**台本**

| 番号 | 話者 | 発言 |
|---|---|---|
| u1 | 看護師 | 佐藤さん、おかえりなさい。305号室の佐藤さんですね、リハビリどうでした？ |
| u2 | 患者 | いやー、きつかったよ。階段の練習させられてさ |
| u3 | 看護師 | 階段！すごいじゃないですか |
| u4 | 患者 | 理学療法士の先生がまた厳しくてね、でも面白い人なんだよ。昔ラグビーやってたんだって |
| u5 | 看護師 | たしかに体格いいですもんね |
| u6 | 患者 | もうお腹ぺこぺこ。お昼来たらすぐ食べたいな |
| u7 | 看護師 | お昼の前にインスリンがあるので、食べる前に声かけてくださいね。先に食べちゃわないでくださいよ |
| u8 | 患者 | わかってるって。あ、汗かいたから着替えたいんだけど |
| u9 | 看護師 | じゃあ血糖測ってから着替えましょうか。182ですね |
| u10 | 患者 | 高い？ |
| u11 | 看護師 | 少し高めですね |
| u12 | 患者 | 午後に娘が来るんだけど、面会って何時からだっけ |
| u13 | 看護師 | 13時からですよ |

**期待する出力**

| 種類 | 中身 | 根拠 |
|---|---|---|
| 患者の照合 | 選んだ 305号室 佐藤さんと一致 | u1 |
| バイタル等 | 血糖 182（「あれば記録」の項目） | u9 |
| 自由記述（患者） | リハビリ（階段練習）後、疲労と空腹の訴え | u2, u6 |
| 依頼 | 着替えたい | u8 |
| 依頼 | 昼食が来たらすぐ食べたい（手がかり：**時間指定・昼食前**） | u6 |
| 手で入力が必要 | 薬の話あり（インスリン） | u7 |
| 抜け | 体温、血圧、脈拍、呼吸数、SpO2 | — |

**見るべき点**

- 理学療法士の人柄・ラグビー・娘の面会の話を記録に入れない
- 面会時間の質問は、その場で答え終わっているのでタスクにしない
- **インスリン（薬）を自由記述・依頼・手がかりに書かない**。「手で入力が必要」に回すだけ。AI が出すのは「昼食前」という時間の手がかりまでで、インスリンをいつ打つかは看護師が決める
- 患者の訴え（u2, u6）と看護師の説明（u7）を1つの文に混ぜない（話者の照合で止まるため）

## 場面3：AI が補ってしまいやすい会話（根拠のない文の検出）

**困りごと**：AI の下書きを鵜呑みにすると、言っていないことが記録に残る。

**状況**：308号室の鈴原さん（架空、80代）。口数が少なく、看護師の話しかけに短く答える。測定も途中まで。

**台本**

| 番号 | 話者 | 発言 |
|---|---|---|
| u1 | 看護師 | 鈴原さん、こんにちは。308号室の鈴原さん、お熱測らせてくださいね |
| u2 | 患者 | はい |
| u3 | 看護師 | 今日は窓から山がよく見えますね |
| u4 | 患者 | うん |
| u5 | 看護師 | 37.4度。ちょっと高めですね |
| u6 | 患者 | なんだか、だるくてね |
| u7 | 看護師 | そうですか。お水は飲めてますか |
| u8 | 患者 | まあ、少しは |

**期待する出力**

| 種類 | 中身 | 根拠 |
|---|---|---|
| 患者 | 308号室 鈴原さん | u1 |
| バイタル | 体温 37.4℃ | u5 |
| 自由記述（患者） | 倦怠感の訴え。飲水は少しはできているとの発言 | u6, u8 |
| 抜け | 血圧、脈拍、呼吸数、SpO2 | — |

**不合格の例**：「感染の疑い」「脱水」「経過観察とする」など、会話にない判断や推測が書かれ、しかも目立たずに出ること。

**どこで止めるか**：根拠の番号が空なら、コードの照合で止まる。しかし Gemini が「脱水傾向あり」に u6（だるい）を根拠として付けると、数も話者も合うのでコードでは止まらない。**二段目の確認で `not_supported` と判定され、目立つこと**が合格の条件。

## 場面4：患者の名前を言い忘れる（取り違えの防止）

**困りごと**：患者の取り違えは安全上最も重大。

**状況**：看護師は名簿で 310号室の小川さん（架空）を選んでから録音した。録音の最初に部屋番号だけ言い、名前を言わない。会話には名簿にない別の患者の名前が出る。

**台本**

| 番号 | 話者 | 発言 |
|---|---|---|
| u1 | 看護師 | 失礼しまーす、310号室です |
| u2 | 患者 | ああどうも。隣の山本さん、昨日退院したんだってね |
| u3 | 看護師 | そうなんですよ、元気になられて |
| u4 | 患者 | いいなあ、俺も早く帰りたいよ。家の猫が心配でさ |
| u5 | 看護師 | 猫ちゃん飼ってるんですね。お熱測りますね。36.5度です |
| u6 | 患者 | 猫は息子が見てくれてるんだけどね |

**期待する動き**

- 患者の照合（コード）：部屋番号は**一致**、名前は**照合できず**（言っていない）。画面は黄色で「310号室 小川さん」を大きく出し、合っているか確認させる。確認が済むまで確定できない
- 会話に出た「山本さん」は名簿にいないので、照合には使わない。山本さんの退院の話を記録に入れない
- 猫・息子の話を記録に入れない

**関連する負例**（spike/test_checks.py（開発用リポジトリの内部資料。提出用には含めていない））：場面1の会話で、名簿の隣の行の「303号室 中田さん」を誤って選ぶと、部屋番号も名前も**食い違い**になり、赤で止まる。

## 場面5：雑談に症状が埋もれる・言い直し・薬（拾い漏れと危ない値）

**困りごと**：その場で残せないと発言を忘れる。雑談を落とすと、雑談に紛れた大事な訴えまで消える。

**状況**：312号室の小林さん（架空、70代）。将棋の話の途中で、ふらついた話がさらっと出る。看護師は体温を言い直す。最後に薬の話が出る。

**台本**

| 番号 | 話者 | 発言 |
|---|---|---|
| u1 | 看護師 | 小林さん、こんにちは。312号室の小林さん、お昼の検温ですね |
| u2 | 患者 | ああ、どうも。さっきまで将棋のテレビ見てたんだよ |
| u3 | 看護師 | 将棋お好きなんですね |
| u4 | 患者 | 若い頃は毎日指してたよ。そういえば今朝トイレに行くとき、ちょっとふらっとして壁に手ついちゃってね |
| u5 | 看護師 | えっ、転んではいないですか |
| u6 | 患者 | 転んではない。すぐ治ったし |
| u7 | 看護師 | お熱は36.8、あ、ごめんなさい、36.6度でした |
| u8 | 看護師 | 血圧は118の70、脈は82、酸素は97です。呼吸は16回ですね |
| u9 | 患者 | 孫がね、今度将棋教えてくれって言うんだよ |
| u10 | 看護師 | いいですね。夕方の薬、いつもの2錠ですからね |

**期待する出力**

| 種類 | 中身 | 根拠 |
|---|---|---|
| バイタル | 体温 **36.6℃**（36.8 は言い直し前の値として出さない）、血圧 118/70、脈拍 82、SpO2 97、呼吸数 16 | u7, u8 |
| 自由記述（患者） | 今朝トイレへ行く際にふらつきあり、壁に手をついた。転倒はなく、すぐ治まったとの訴え | u4, u6 |
| 手で入力が必要 | 夕方の薬（2錠）の話あり | u10 |
| 抜け | なし | — |

**見るべき点**

- 将棋・孫・テレビの話は落とすが、同じ発言（u4）に混ざった**ふらつきは必ず拾う**
- 「起立性低血圧の疑い」などの推測を書かない
- 薬の量（2錠）を自由記述に書かず、「手で入力が必要」に回す

## 評価用に取り置く場面

プロンプトを場面1〜5に合わせて直していくと、その5本でだけ合格する形になりやすい。そこで、**プロンプトの調整に使わない場面を2本、別の人が書いて取り置く**。最後の確認だけに使う。【未決】Aさんに書いてもらう案。

## まだ足りない場面（時間があれば）

- 病室の雑音が多い、声が小さい（文字起こしの精度）
- 同姓の患者がいる
- 会話の途中で別の患者やスタッフが話しかけてくる
- 看護師が値を声に出さない（7章の逃げ道の確認）
