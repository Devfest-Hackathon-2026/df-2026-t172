# 非機能要件

機能の外側で守る水準（速さ・止まらないこと・費用・データの置き場所など）をまとめる。決まりの番号は [決まりの一覧](rules.md)、API の形は [データの形](data-model.md)。食い違ったら rules.md を優先する。

- **数値に根拠がないものは「仮置き」**と書いた。技術検証と 11/8 の通しで測った値が出たら置き換え、変更履歴に書く
- 「測り方」は、提出後に人が触れなくなる前に確かめられる方法を書いた

## 一覧

| 分野 | 要件 | 数値の根拠 | 測り方 |
|---|---|---|---|
| 応答時間 | 録音停止から下書き表示まで、**テキスト入力で 20秒以内、1分の音声で 40秒以内**（どちらも中央値） | **仮置き**（Gemini を2回・Speech-to-Text を1回続けて呼ぶ。実測がない）。看護師がベッドサイドで待てる長さとして置いた | 操作記録の「録音停止」と「下書き表示」の時刻の差（設計 [9章](README.md#9-計測用の操作記録)）。live で利用シーン5場面を通して測る |
| 同時利用 | **1人が使うことを想定**。審査員が数人同時に触った場合は、インスタンス1台で受ける（待ちが長くなることは許す） | 審査の使い方の想定。数人同時に触ったときの動きは**未検証** | 提出前に2つの端末から同時に下書きを作り、両方返るかを見る（人） |
| 可用性 | 提出後（11/10 19:00〜11/14）は再デプロイ・設定変更・手動の再起動・認証の更新ができない。**人が触れなくても動き続ける**こと。Cloud Run は最大1インスタンス（C-01） | ハッカソンの決まり（H-03） | 提出前に、次を人が確かめる：認証がサービスアカウントで、期限のある鍵を使っていない（SEC-03）／使うモデルの廃止日が 11/14 より後（[ADR-0004](../adr/0004-model.md)）／TTL の設定が入っている（P-03） |
| 起動の待ち | 【未決】最小インスタンス数。0なら費用は抑えられるが、しばらく使われなかった後の最初の1回が遅くなる | — | 提出前に、しばらく置いてから最初の1回の応答時間を測る（人） |
| 失敗したときの扱い | Gemini・文字起こしが失敗したら **502** と、画面にそのまま出せる日本語の言葉を返す。**勝手にモックの結果に切り替えない**（C-05）。二段目の確認が失敗したら、全文を「判断できない」として返す（C-06）。思わぬ失敗は 500 で、中身を出さない（SEC-05）。1日の上限に届いたら 429（全体 `daily_limit`、IP ごと `client_daily_limit`）、音声・テキスト・JSON 本文（1MB）が大きすぎたら 413、画面が送り返す下書き・発言の列が上限（発言200件など、`backend/app/models/limits.py`）を超えたら 422 | rules.md | `test_C05_draft_failure_is_502`、`test_C05_failure_is_reported_not_replaced_by_mock`、`test_C06_entail_failure_flags_every_sentence`、`test_SEC05_unexpected_error_hides_internals`、`test_C04_daily_limit_stops_before_calling`、`test_SEC04_*` |
| 費用の上限 | 使えるのは Cloud Credit の **20ドル（約3,000円）**。有料の呼び出しは **1日 300回まで**、IP ごとに30回まで（C-04。下書き1回＝テキスト2回・音声3回と数える）。予算アラートは 1,000円・2,000円・2,500円（C-02、**通知だけで止めない**） | 20ドルはクレジットの額。300回/日は「審査員が普通に試して届かない数」として決めた（根拠の実測はない）。**1回あたりの費用はモデルが決まってから測り直す**（予定のモデルが廃止されたため。[ADR-0004](../adr/0004-model.md)） | 呼び出しごとのトークン数（思考トークンを含む）と費用を Cloud Logging に出す（C-03）。通しの後に「1回の費用 × 300回 × 提出後の日数」がクレジットの残りに収まるかを計算する（人） |
| データの置き場所 | Firestore と Cloud Run は東京（`asia-northeast1`）。Speech-to-Text も既定は `asia-northeast1`（日本語の話者分離が使えるかは未検証）。Gemini は `gemini-3.5-flash` を **`global`** で呼ぶ（東京は従量課金で呼べないため。P-05 の例外として 11/8 に決定） | P-05 | 設定で確かめる（人） |
| 保存の期間 | 記録とタスクは作った日の翌日0時以降に TTL で消す。TTL は期限ちょうどではなく、**期限を過ぎてから消す**ので、しばらく残ることがある | P-03 | `test_P03_expires_at_next_midnight`（期限の値）。実際に消えるかは、提出前に前日の記録が残っていないかを見る（人） |
| 入力の大きさ | 音声は3分・10MB、テキストは5,000文字まで（SEC-04、超えたら 413）。`/api/verify`・`/api/records` で画面が送り返す下書きと発言の列にも件数の上限がある（発言200件、文は S・O それぞれ50、根拠は3件など。超えたら 422） | 費用と停止を防ぐ上限として決めた（仮置きに近い。会話の長さの実測はない） | `test_SEC04_*` |

## 決めきれていないこと

| 何を | なぜ決められないか |
|---|---|
| 応答時間の数値 | 実測がない。モデルも決まっていない |
| 最小インスタンス数（0 か 1） | 費用と最初の1回の速さの兼ね合い。チームで決める |
| Gemini の呼び先のリージョン | 替えのモデルが東京で従量課金で使えるかを確かめている |
