# ヒアリング記録

現場の人に聞いた内容と、そこからチームが決めたことの記録。説明ドキュメントの「誰の、どんな課題か」と、動画の「現場の声」の元にする。

- 聞いた相手は立場だけを書き、名前は書かない
- **聞いた事実**と**チームの解釈**を分けて書く。解釈は事実ではないので、資料で使うときは「私たちはこう考えた」と書く
- 聞けたのは看護師1名だけ。1人の経験を現場全体に一般化しない

## 1. 看護師（11/6）

### 聞いた事実

**業務の様子**

- 受け持ち患者の清拭・着替え、バイタル測定、点滴、手術や退院の準備に加え、入院の対応もある
- 認知症の患者が手術を覚えておらず動いて転倒する恐れがあり、センサーマットで見守る。その対応で他の業務が進まないことがある
- 看護カルテには当日やることと時間が書いてあるが、予定どおりに進むとは限らない
- 経験の浅い看護師は、業務の全体像や患者の回復状況をつかみにくく、優先順位に悩む

**看護記録**

- 患者から聞いた症状などをメモし、後でパソコンから看護カルテに入力している
- 記録は大事だが時間がかかる。その場で残せないと、患者の発言を後で思い出せないことがある
- 一人で患者を回りながら、測定・聞き取り・記録をこなす負担がある
- 基本の項目（体温などのバイタル）はフォーマットどおりに記入し、それ以外は自由記述で書く。どちらも一度メモしてからパソコンに入力し直している（追加の質問で確認）

**食事・アレルギー（当初の②に関係）**

- 食物アレルギーは患者に確認し、紙と電子カルテに記録する。献立によっては、調理側から出汁などの可否を聞かれる
- 患者本人が知らなかったアレルギーが後から分かることもある
- 食事前にインスリンを打つ患者で、スタッフ間の共有が足りない場合や、患者がリハビリから戻って先に食べてしまう場合に、打ち漏れにつながる心配がある
- 配膳は看護師だけでなく、看護助手や栄養管理士もする。食事の置き場所に注意書きを置いて対応している

**医師への確認（当初の③に関係）**

- 手術後は、点滴、食事を始める時期、移動の方法、薬の再開など、患者ごとに医師へ確認することが違う
- 対応が立て込む中で確認を忘れると、後から医師に連絡してもつながらないことがある
- 「医師に確認することを整理する」案には「便利そう」という反応だった

**その他**

- 障害のある人との面談で、本人の発言と看護師の考えを分けて記録する案（当初の④）も話題に出たが、困りごとの具体例は聞けなかった

### 当初の案への反応

| 当初の案 | 反応・聞けたこと | チームの判断 |
|---|---|---|
| ② 配膳する人向けの除去食カード | アレルギーや食事指示はすでに紙と電子カルテで確認する仕組みがある。カードで表示するだけでは何が良くなるか分からない、という意見 | 保留。困りごとは「表示」ではなく「誰が何を確認し、誰に伝えるか」の流れにあり、カードでは解けない |
| ③ 受診前に「医師に聞きたいこと」を整理（患者向け） | 具体的に出たのは患者側ではなく、**看護師が医師に確認することの聞き忘れ** | 患者向けの元案はいったん外す。看護師側の確認事項は新しい案に取り込む候補 |
| ④ 意思決定支援の記録 | 発言と判断が混ざることで、具体的にどんな困りごとが起きるかは聞けなかった | 保留。必要とされる場面の確認が足りない |

## 2. 看護師への追加の質問（11/6〜11/7）

### 聞いた事実

- 看護記録は、基本の項目（バイタルなど）をフォーマットどおりに書き、それ以外は自由記述（上の「看護記録」に反映済み）
- 「患者さんごとに録音ボタンを押す」形を話したところ、**負担はなく、あったら嬉しい**という反応だった

### まだ答えをもらっていない質問（11/7 時点）

| 質問 | 何が決まるか |
|---|---|
| 自由記述に決まった書き方はあるか（SOAP など） | 下書きの枠 |
| バイタルは測定器から自動で入るか、手で入力しているか | バイタルを声で入れる機能が要るか |
| 病院で患者との会話を録音することは許されそうか | 録音する前提が成り立つか。駄目なら「病室を出てから声でメモする」形に変える |
| 患者からの依頼は、今どう覚えて、他の人にどう伝えているか | タスク画面と引き継ぎの機能 |
| 依頼を忘れた・後回しになって困った例 | タスク化が本当に要るか。デモの例 |
| やることの順番を何を見て決めているか | タスクに付ける情報 |
| 医師に確認したいことを今どこに控えているか、聞き忘れた例 | 医師への確認事項を入れるか |
| 持ち歩く端末は何か。相部屋で患者の前で話して記録できるか | 録音のやり方 |
| AI の下書きの確認に、1人あたり何分まで使えるか | 確認画面にどこまで出すか |
| 下書きの文ごとに「会話のどこから来たか」が見られたら、実際に見るか | 根拠表示が差別化として効くか |

## 3. ケアマネジャー（予定していたが実施できず）

- 当初の①（住宅改修の理由書の材料整理）について、11/6 に聞く予定だった
- 連絡はしたが、ヒアリングの時間が取れなかった（11/7 0:04 時点）
- 「テンプレートが決まっていて、材料がバラバラ」な書類は AI が得意な形で、①は条件に合う。そのため 11/7 中に聞ければ①に戻すことも考えたが、聞けないため看護記録の案で進めることにした
- **①は否定されたのではなく、確かめられなかった**。資料で触れる場合はそう書く

## 4. ここから決まったこと（11/7 時点、3人で合意）

詳しい比較と理由は [ADR-0006](../adr/0006-theme-nursing-record.md)。

- 作るもの：看護師がベッドサイドで録音ボタンを押し、「302号室の田中さん」と言ってから話すと、AI がバイタルを決まった項目に入れ、残りを自由記述の下書きにし、患者からの依頼をタスクとして出す。看護師が確認・修正して確定し、カルテに貼れる形で出す
- 狙う困りごと：**メモしてからパソコンに入力し直す二度手間**と、**その場で残せず発言を忘れること**、**依頼が他の業務に埋もれること**
- 採らなかったこと：常時録音と声紋での患者識別（同意・個人情報・検証期間の問題。[ADR-0006](../adr/0006-theme-nursing-record.md)）

## 5. このヒアリングの限界

- 看護師1名の経験で、病院や病棟が変われば記録の仕方も違う可能性が高い
- ヒアリングの場で案を見せているので、「便利そう」「あったら嬉しい」は気を遣った答えの可能性がある。使うかどうかは、試作を実際に試してもらって確かめる
- ケアマネジャーには聞けていない
