# 0002. Gemini は Vertex AI 経由で呼ぶ

- 状態：決定
- 日付：2026-11-05
- 決めた人：Cさん（チームで最終確認する）

## 背景

ハッカソンでは、Google 技術がプロダクトの中核であることが審査される。配布される Cloud Credit は1チーム20ドル（約3,000円）で、**Google AI Studio には使えない**（キックオフ資料）。

## 比べた案

| 案 | 利点 | 欠点 |
|---|---|---|
| A. Google AI Studio の API キーで Gemini を呼ぶ | 設定が簡単。無料枠がある | Cloud Credit が使えない。無料枠の制限に当たると止まる。API キーの管理が必要 |
| B. Vertex AI 経由で Gemini を呼ぶ | Cloud Credit が使える。Cloud Run のサービスアカウントで認証でき、API キーを持たずに済む。予算アラートで費用を見られる | 初期設定（API の有効化、権限）が少し多い |
| C. 他社の LLM API を使う | — | ルール上禁止ではないが、Google 技術として評価されない |

## 決めたこと

B を採る。Cloud Run からはサービスアカウントで Vertex AI を呼び、API キーは使わない。

## 選んだ理由

- クレジットを使えるのは Vertex AI だけ
- API キーをコードや環境変数に置かずに済むので、公開リポジトリで秘密情報を漏らす危険が下がる（審査の「安全性」）

## 捨てた案と、捨てた理由

- A：クレジットが使えず、キーの管理が要る
- C：審査で評価されない

## この決定で困ること・後で見直す条件

- ローカル開発では `gcloud auth application-default login` が必要。チーム全員が同じプロジェクトの権限を持つ必要がある
- 費用の事故を防ぐため、予算アラート（例：1,000円・2,000円・2,500円）を設定し、思考モードは必要なとき以外止める（[ADR-0004](0004-model.md)）

## AI の使い方

料金と仕組みは、AIに公式の料金ページを調べさせて確認した。AI Studio にクレジットが使えない点は、キックオフ資料で人が確認した。
