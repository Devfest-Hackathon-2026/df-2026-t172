## 必ず守ること（キックオフ資料より）

- [ ] Drive フォルダを「リンクを知っている全員が閲覧可」にする（開けないと審査されない）
- [ ] デプロイした URL を、提出用リポジトリの README に書く
- [ ] デプロイ URL を **11/14（土）まで動かし続ける**（クレジットの残額と期限を確認）
- [ ] API キーや秘密情報をリポジトリに入れない
- [ ] デモ動画を偽装しない（実際に動くものを映す）
- [ ] デモ・ピッチで他社製品を前面に出さない
- [ ] カテゴリ（医療・福祉）から外れていないか、最後に確かめる

## 審査の配点（各0〜3点×8項目、合計24点）

| 観点 | 配点 | 中身 |
|---|---|---|
| プロダクトの完成度 | 9 | a. 一連の流れとして動く ／ b. 対象ユーザーが目的を達成できる UI・UX ／ c. 安全性・拡張性・保守性 |
| Google 技術の活用 | 6 | a. 中核で有効に機能 ／ b. 採用理由が合理的・具体的 |
| 社会課題への解決力 | 6 | a. 課題が具体的・明確 ／ b. 機能が課題解決に有効 |
| ピッチの構成と説明力 | 3 | デモと話の構成（オンライン会場は動画で評価） |
