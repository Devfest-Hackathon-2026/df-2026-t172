# プレゼン動画の構成（下書き）

オンライン会場はピッチがなく、**この動画でピッチの観点（3点）が評価される**。決勝の Demo Day は1チーム6分（デモと発表5分＋質疑1分）で「Demo-first」（何を作ったか、なぜ作ったか → デモ）とされているので、動画も同じ考え方で作る。

長さは運営の指定を確認する（未確認）。ここでは5分で組む。

| 時間 | 内容 | 見せるもの |
|---|---|---|
| 0:00〜0:30 | 何を作ったか（一言） | 完成した画面 |
| 0:30〜1:15 | 誰の、どんな課題か | 根拠データ1〜2個と、ヒアリングで聞いた現場の言葉 |
| 1:15〜3:30 | デモ（一連の流れを止めずに） | 入力 → Gemini の整理と根拠表示 → 人が承認・修正 → 出来上がり |
| 3:30〜4:15 | なぜこの作り（Own the Why） | AI に判定させない理由、Google 技術を選んだ理由（ADR から） |
| 4:15〜4:45 | 安全性と、これから | 個人情報・誤りへの備え、本番で必要なもの |
| 4:45〜5:00 | 締め | 一言 |

## 注意

- 実際に動くものを映す（偽装は審査対象外）
- 他社製品を画面や話の前面に出さない
- 字幕を付ける（音声だけに頼らない）
- 撮り直しの時間を見込み、**11/9 中に一度通しで撮る**
