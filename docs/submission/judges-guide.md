# 審査員向けの使い方

> 提出用リポジトリの README とプロダクト説明ドキュメントに写す。**合言葉の値は、公開の GitHub には書かず、提出物の Google Drive にあるプロダクト説明ドキュメントにだけ書く**（GitHub は誰でも見られ、検索にも載るため）。

## 開く

- URL：https://nursing-draft-live-655696596429.asia-northeast1.run.app
  - 本物の Gemini と文字起こしを使う版です。画面の右上に **「本番」** と出ます
- 合言葉：**プロダクト説明ドキュメント（提出物の Google Drive）に書いてあります**
  - 最初の画面で入力してください。合言葉は、URL を見つけただけの人に使わせないためのものです
- **Safari か Chrome で開いてください**。LINE などのアプリの中で開くブラウザでは、録音が使えないことがあります（その場合は「テキストで入力」を使ってください）
- パソコンかスマートフォンで開けます。録音を試す場合は、ブラウザがマイクの使用を求めたら許可してください
- 録音に対応していない環境では「Safari か Chrome で開いてください」と表示します。「テキスト入力へ」を押すと、選択した患者のまま会話を入力できます。マイクの権限がない場合は、ブラウザの設定で許可して再試行することもできます

## 試し方（5分ほど）

1. **患者を選ぶ**：マイクのボタン（録音）か「テキストで入力」を押すと、名簿が出ます。名簿は**架空の患者6人**（東3病棟、302〜312号室）で、実在の人ではありません。あわせて「最初に話す人」（自動・看護師・患者）を選べます
2. **会話を入れる**：次のどちらかです
   - 録音：「録音」を押す前に「患者の同意を得ましたか」の確認が出ます（本番では患者本人に口頭で同意を取る前提です）。看護師と患者の役で話します。**1回3分まで**
   - テキスト：ホームの「テキストで入力」、または録音できなかったときの「テキスト入力へ」から、録音の代わりに次のような会話を貼れます（1行1発言、`看護師:`・`患者:` で始める）
     ```
     看護師: 302号室の田中さん、検温に来ました。
     看護師: 体温36度8分です。血圧は132の78ですね。
     患者: 夜中に傷が痛くて、あまり眠れなかったです。
     患者: あとでタオルをもう1枚もらえますか。
     ```
3. **下書きを確かめる**：数秒〜数十秒で下書きが出ます。「根拠を確認」から、**根拠になった発言**を確認できます。検証結果の「発言6」などの番号を押すと、そのカード内に該当する発言が開き、対象が枠で示されます。根拠の欄と会話の文字起こしにも同じ番号が付いています。根拠で裏付けられない文は色が付き、1文ずつ「残す／消す」を選ぶまで確定できません。下書きの文を直すと照合をやり直し、直した文は確定のときに「根拠の発言から言えるか」を判定し直します
   - 話者が逆の場合：「会話の文字起こし」を開き、「看護師と患者を入れ替える」を押します。発言番号・本文・時刻と話者不明の発言はそのままに、看護師と患者のラベルを一括で入れ替えます。下書き本文は自動で書き直されないため内容を確認し、「再検証」を押してください。変更前の「残す／消す」の選択は解除され、再検証が終わるまで確定できません
4. **確定する**：看護師が確かめてから確定すると、電子カルテに貼れる形の文が出ます（先頭に患者の名前・部屋・日時）
5. **タスクを見る**：会話の中の患者の依頼（「タオルをもう1枚」など）が、タスクの一覧に出ます。並びの段（急ぎ・時間指定・ほか）は AI ではなく、会話の手がかりからコードが決めています
   - タスクの変更：一覧では部屋番号・名前・区分・分類を1行で表示します。未完了タスクを押すと「タスクを変更」が開き、区分・分類・担当をまとめて選べます。区分は「急ぎと言われた」「時間指定あり」「その他」の3つです。一覧では「急ぎ」「時間指定」「その他」と短く表示します。「変更する」で反映され、「キャンセル」や閉じる操作では変更されません
   - 分類の変更：一覧の「物品」「食事」などは表示用のタグです。変更する場合はタスクを押し、同じ編集画面の「分類」から選びます。緊急度を変えずに分類だけを保存することもできます。完了済みのタスクは表示のみです
6. **担当の変更を試す**：看護師は架空の4人です。ログインはありません
   - 最初に、タスクの一覧の上の「自分」で名前を選びます（このタブを閉じると消えます）。「自分の担当」を押すと、自分が担当のタスクだけになります
   - 各タスクの下に「担当：〇〇」と出ます。作ったときは、その患者の受け持ちの看護師が担当です
   - 未完了タスクを押し、「タスクを変更」の「担当」で別の看護師を選んで「変更する」と、担当が変わります（担当に回す・自分で引き取る）。保存されるので、再読み込みしても、ほかの人の画面でも同じです
   - タスクの画面のいちばん下の「受け持ちを変える」で、患者ごとの受け持ちを変えられます。まだ誰も担当を変えていない未完了のタスクも、新しい受け持ちに移ります
   - 担当・受け持ちを変えた人と確定した人は、選んだ「自分」の**自己申告**として残ります（「タスクを変更」と記録の詳細に出ます）。本人の確かめはありません。合言葉を共有しているので、ほかの審査員が担当を変えることがあります

選んだ患者と、会話で言った部屋番号・名前が食い違うと、赤で止まります（取り違えの防止）。名簿の別の患者（例：303号室の中田さん）を選んで、上の会話を入れると確かめられます。

## 知っておいてほしいこと

| 項目 | 内容 |
|---|---|
| 1日の上限 | 費用の事故を防ぐため、AI を呼ぶ回数に1日の上限があります（アプリ全体で300回、同じ接続元から30回。下書き1回でテキストなら2回、録音なら2回＋1分ごとに1回ほどを数えます）。上限に達すると「今日の利用回数の上限に達しました。明日もう一度お試しください」（接続元ごとの上限なら「この端末からの今日の利用回数の上限に達しました。明日もう一度お試しください」）と出ます。日本時間の0時に戻ります |
| データの保存 | 音声と会話の全文は保存しません。確定した記録とタスクだけを保存し、**作った日の翌日0時以降に自動で消えます**（消えるまで最大1日ほど遅れることがあります）。他の審査員が試した記録やタスクが見えることがあります |
| 失敗したとき | AI や文字起こしが失敗したときは、その旨を画面に出します。代わりに見本の結果を出すことはしません |
| AI の役割 | AI が作るのは下書きだけで、確定するのは看護師です。診断・薬の名前と量・依頼の優先順位は AI に書かせません |
| 録音の聞き違い | 部屋番号を聞き違えることがあります（例：「310号室」が「315号室」）。名簿にない部屋番号なら黄色（確かめて）で止まるので、名簿で確かめてから「この患者で正しい」を選んでください。名簿のほかの患者の部屋番号や名前が出たときは、赤で止まります |
