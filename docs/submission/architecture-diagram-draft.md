# アーキテクチャ図の描き方（下書き）

提出用の Google Cloud アーキテクチャ図を、公式アイコン（https://cloud.google.com/icons）で描くための下書き。中身は [architecture.md](architecture.md) と同じで、ここでは**どこに何を置き、矢印に何と書くか**だけを決める。描いた図は Drive に出し、画像（PNG）を `docs/submission/architecture.png` に置いて architecture.md と README に貼る。

## 1. 全体の配置（左から右へ流れる）

```
┌───────────┐    ┌──────────── Google Cloud（プロジェクト）──────────────────────────────┐
│ 看護師の   │    │ ┌─ asia-northeast1（東京）──────────────┐   ┌─ us ──────────────┐ │
│ スマホ・PC │─①─▶│ │                                       │─②▶│ Speech-to-Text     │ │
│（ブラウザ）│◀④──│ │  Secret Manager ──▶ Cloud Run          │◀──│                    │ │
│            │─⑤─▶│ │                     │   │   │           │   └────────────────────┘ │
└───────────┘    │ │                     │   │   └───③──────┼─▶ ┌─ global ──────────┐ │
                 │ │          Firestore ◀┘   └─⑥▶ Cloud Logging│◀── │ Vertex AI（Gemini） │ │
                 │ └───────────────────────────────────────┘    └────────────────────┘ │
                 │   Cloud Billing（予算アラート）- - - ▶ チーム（通知だけ）               │
                 └─────────────────────────────────────────────────────────────────────┘
```

- **リージョンを枠で分ける**のがこの図の要点。保存（Firestore）と秘密（Secret Manager）は東京、AI の処理だけが東京の外（global・us）にあることが一目で分かるようにする
- ブラウザは Google Cloud の枠の外に置く
- 予算アラートは点線で「通知だけ」と分かるようにする

## 2. 置くもの（アイコンと文言）

| アイコン（公式アイコン集の名前） | 置く枠 | 箱に書く文言 |
|---|---|---|
| （一般アイコン：スマートフォン／ノート PC） | 枠の外 | 看護師のスマホ・PC（ブラウザ）<br>音声は送るまで端末のメモリだけ |
| Cloud Run | 東京 | Cloud Run（最大1インスタンス）<br>FastAPI が画面と API を配信<br>根拠の照合・患者の取り違えの確認はコード |
| Vertex AI（Gemini のアイコンがあれば並べる） | global | Vertex AI：Gemini（gemini-3.5-flash）<br>① 根拠つきの下書き ② 再確認 |
| Speech-to-Text | us | Speech-to-Text V2（chirp_3）<br>文字起こし・話者分離・時刻 |
| Firestore | 東京 | Firestore<br>確定した記録・タスクだけ<br>翌日0時以降に自動で消す（TTL） |
| Secret Manager | 東京 | Secret Manager<br>合言葉・署名の鍵（バージョン固定） |
| Cloud Logging | 東京の枠の近く | Cloud Logging<br>時刻・トークン数・費用<br>（会話の文・患者名は出さない） |
| Cloud Billing | プロジェクトの枠の下 | 予算アラート（通知だけ） |

## 3. 矢印（番号は処理の順）

| 番号 | 向き | 矢印に書く文言 |
|---|---|---|
| ① | ブラウザ → Cloud Run | HTTPS・合言葉<br>録音（3分まで）または文字 |
| ② | Cloud Run ⇄ Speech-to-Text | 音声（FLAC に変換し 55秒ずつ区切る）→ 話者つきの発言の列 |
| ③ | Cloud Run ⇄ Vertex AI | 発言の列 → 下書き（根拠の発言番号つき）と再確認<br>サービスアカウントで認証（API キーなし） |
| ④ | Cloud Run → ブラウザ | 下書き＋コードの照合の結果 |
| ⑤ | ブラウザ → Cloud Run → Firestore | 看護師が確かめて確定 → 記録・タスクと、根拠になった発言だけを保存 |
| ⑥ | Cloud Run → Cloud Logging | 操作の記録（JSON 1行） |
| — | Secret Manager → Cloud Run | 起動時に環境変数で渡す |
| 点線 | Cloud Billing → チーム | 費用が超えたら通知（止めはしない） |

## 4. 図の下に添える一文（任意）

- 音声と会話の全文は保存しない。残すのは確定した記録と、その根拠になった発言だけ
- 使わないもの：Cloud Storage（音声を一時的にでも保存しないため）

## 5. 描くときの注意

- アイコンは公式のものをそのまま使い、色や形を変えない（公式アイコン集の利用の決まりに従う）
- 他社の製品のアイコンやロゴは入れない
- 文字は図を縮めても読める大きさにする（動画やドキュメントに貼るため）
