# 守らせる決まり

このアプリの決まりは、番号つきで `docs/design/rules.md` にまとめてある（8分野：患者の安全 S、AI の扱い A、個人情報 P、セキュリティ SEC、費用と止まらないこと C、記録の形 R、人が守る運用 O、ハッカソン H）。**コードを書く前に、関わる決まりを確かめる。**

#[[file:docs/design/rules.md]]

## 守り方

- 守らせる場所が **B**（バックエンド）の決まりは、コードで強制してテストで確かめる。テスト名に番号を入れる
- **F**（画面）だけで守らせる決まりは作らない。画面の作りに漏れがあっても安全が崩れないよう、大事なものは B でも止める
- 決まりに反する変更が必要に見えたら、コードを書かずに、どの決まりとどうぶつかるかを人に伝える
- 決まりを足す・変えるのは人。案を出すときは、番号・決まり・なぜ・守らせる場所・確かめ方を `rules.md` の表の形で書き、変更履歴に1行足す

## 特にぶつかりやすいもの

| 番号 | 中身 |
|---|---|
| A-02 | AI が書くのは SOAP の S と O だけ。A と P は常に空 |
| A-05 | 「止める」が付いた文は、1文ずつ残す／消すを決めるまで確定できない（409） |
| A-07 | 薬の名前・量・回数は AI に書かせない |
| A-08 | 依頼の緊急度はコードが会話の手がかりから決める。AI は優先度を書かない |
| A-09 | 選んだ患者の情報を Gemini に渡さない |
| S-01〜S-03 | 患者は名簿から選ぶ。照合が黄・赤なら看護師の確認なしで確定できない |
| P-01・P-02 | 音声と会話の全文を保存しない |
| P-04 | ログに会話の文・患者名を出さない |
| C-05 | 失敗したら分かる言葉で返す。勝手にモックの結果に切り替えない |
